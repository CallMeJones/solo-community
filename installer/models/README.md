# Solo packaged embedding model

Official Community installers include the quantized `all-MiniLM-L6-v2`
ONNX model so first-run memory and document workflows work offline.

The binary files are fetched only while assembling a release. Their source
revision, target names, license, and SHA-256 digests are pinned in
`embedding-model.json`; the model is not committed to this repository.

Source: <https://huggingface.co/Xenova/all-MiniLM-L6-v2>
