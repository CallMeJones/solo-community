# Solo Community 0.12.0

Solo 0.12.0 is the first clean-root Community release candidate for Windows and
Ubuntu desktop users.

## Included

- one encrypted local Memory Library at `solo.db`;
- unlimited memories, documents, imports, and logical projects;
- local semantic recall with the packaged offline embedding model;
- MCP stdio, authenticated local HTTP/MCP, CLI, Desktop, and system tray;
- graph exploration, memory inbox/review, project context, diagnostics, backup,
  restore, and retained-source workflows;
- Windows installer and ZIP candidate artifacts;
- Ubuntu 24.04 x86-64 `.deb` candidate with desktop entry, autostart support,
  Secret Service keyring integration, and installed tray launch smoke.

## Edition boundary

Community does not contain a chat-agent runtime, database/tenant/profile
management, a database selector, hosted control-plane code, Pro modules, or Enterprise
modules. The release gate inspects CLI help, OpenAPI, configuration, embedded
Web assets, installed workflows, and the on-disk layout for that boundary.

## Candidate status

This is a release candidate until the signed/unsigned Windows installer policy,
the Ubuntu package, first-run experience, backup/restore, and real desktop tray
behavior have been accepted on physical Windows and Ubuntu machines. Candidate
artifacts are not a promise of production support.

## Upgrade safety

Solo promotes the prior default-library layout to `solo.db` only when it is
unambiguous. If additional legacy databases exist, startup stops and asks the
operator to export them instead of guessing which data to discard.
