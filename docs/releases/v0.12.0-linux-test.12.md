# Solo 0.12.0 Linux test 12

Public pre-release candidate for hands-on Ubuntu 24.04 x86-64 testing and
Windows upgrade validation.

- supersedes Linux test 11 by updating the transitive `webbrowser` dependency
  from 1.2.1 to 1.2.2, resolving RUSTSEC-2026-0257;
- preserves the real 0.11.x `.solo` profile migration compatibility from test
  11, including previous `tenants/default.db` promotion and legacy registry
  quarantine behavior;
- installs the generated `.deb` in CI and runs memory, document, backup,
  restore, MCP, single-database, and tray GUI smokes against the installed app.

This is not the stable 0.12.0 release.
