# Solo 0.12.0

First general release of Solo Community. Local-first personal memory for AI
assistants, with the memory graph, Solo Controls, and in-app updates.

## Updating from inside Solo

Solo Controls can now update itself. **Check for updates** asks GitHub for the
newest Community release; **Install** downloads it and verifies the published
SHA-256; **Install and restart** stops the daemon, runs the installer and brings
Solo back.

Nothing polls. Solo is local-first and its installers are offline-first, so
GitHub is contacted only when the button is pressed, and nothing is reported
home.

On Ubuntu the flow stops at a verified download, because a `.deb` needs root and
cannot install unattended. Solo Controls shows the command to run.

## Solo Controls

- Back and Solo Controls navigation on every section; previously Settings and
  Connected Tools could be entered but not left.
- Page-level scrolling across the window, and sideways scrolling on the
  connected-clients table so its actions are always reachable.
- Theme picker offering System, Dark, Light and Dune.
- Find install probes for Claude Desktop, Cursor and the Codex CLI, reported
  separately from their Solo config — a config path exists whether or not the
  client does.
- Settings and Logs reachable directly from the main row.

## Solo Desktop

- Four themes: Dune, Dark, Light and Dark Blue, applied without a reload.
- Six memory-graph palettes, each with variants tuned for light and dark
  surfaces. Edge and particle colours derive from the node palette, so
  recolouring the graph stays coherent.
- Optional glow and animated flow along the connections, in both 2D and 3D.
  Enabled by default, and off by default where the system asks for reduced
  motion.

## Verifying a download

Every package ships a `.sha256` beside it. The installers are not yet
code-signed, so Windows will show its unknown-publisher prompt; compare the
checksum if you want to confirm what you downloaded.

## Install

Windows: run `SoloSetup-0.12.0-x86_64.exe`. It installs per-user, without an
administrator prompt.

Ubuntu 24.04 x86-64: `sudo apt install ./solo-0.12.0-ubuntu24.04-amd64.deb`
