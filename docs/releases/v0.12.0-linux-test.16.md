# Solo 0.12.0 Test 16

Public pre-release candidate completing the Dune theme in Solo Controls, and
the first release that can be applied entirely from the Check for updates
button.

- fixes the Dune page background, which stayed neutral grey while the buttons,
  borders and text went warm; the central panel painted a fill derived only
  from dark-vs-light straight over the theme's own surface colour.

Test 15 shipped the installer-handoff fix but could not use it, because the
handoff runs in the build being replaced rather than the one arriving. Updating
from test 15 to this release exercises the whole path — check, download,
verify, install, restart — without a manual step.

This is not the stable 0.12.0 release.
