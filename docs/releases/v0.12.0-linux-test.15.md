# Solo 0.12.0 Test 15

Public pre-release candidate fixing the in-app updater found by hands-on
Windows testing of test 14, and adding the Dune theme to Solo Controls.

- fixes the installer handoff, which failed with "Windows cannot find" and left
  the update downloaded but never applied; the command was quoted by the rules
  `CommandLineToArgvW` uses rather than the ones `cmd.exe` actually parses;
- stops the spurious red failure shown the moment a download starts: the
  request that begins the job and the first status poll race, and a status of
  idle was being reported as a lost job instead of one not yet picked up;
- covers the handoff with a test that runs the real mechanism against a path
  containing spaces, rather than only asserting the command string;
- adds Dune to the Solo Controls theme picker, alongside System, Dark and
  Light, matching Solo Desktop's default palette.

Updating to this release from test 14 will download and verify, then fail to
apply, because the handoff fix ships *in* this build and cannot run from the
one replacing it. Run the downloaded installer once by hand; updates after this
one apply from Solo Controls without that step.

This is not the stable 0.12.0 release.
