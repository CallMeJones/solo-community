# Solo 0.12.0 Linux test 9

Public pre-release candidate for hands-on Ubuntu 24.04 x86-64 testing.

- supersedes Linux test 8 by applying one shared digest-aware, fail-closed
  uploader to Linux test releases and future stable Windows, Linux, and SDK
  release assets;
- retains matching assets, resumes missing assets, and refuses to delete or
  replace mismatched, duplicate, or unverifiable assets;
- uses Node.js 24 artifact upload and download actions, each pinned to an
  immutable, verified upstream commit;
- includes the verified upstream `glib` iterator soundness fix backported into
  the GTK 3 dependency line;
- installs the generated `.deb` in CI and runs memory, document, backup,
  restore, MCP, single-database, and tray GUI smokes against the installed app;
- publishes the package and checksum only after every release gate succeeds.

This is not the stable 0.12.0 release.
