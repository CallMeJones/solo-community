# Solo 0.12.1

Patch release fixing the in-app updater and the cost of the memory viewport.

## Updates

- The Install button no longer offers a release that is already installed.
  Official builds are produced from a branch, so the ref baked into them names
  no release tag; the check fell through to "not among the recent releases" and
  offered the newest one forever. It now compares the version the release's own
  package advertises against the running version.

This is why the version moved to 0.12.1 rather than shipping another 0.12.0
package. The fix compares versions, so a build that also called itself 0.12.0
could never reach anyone already running 0.12.0.

## Memory viewport

The 2D graph held about 17% of a CPU core while sitting still, at 51fps. It now
runs at 165fps for under 2% — the same as with effects switched off.

- Node glow ran a gaussian blur per node per frame. A halo depends only on the
  node's colour, so it is now rendered once per colour into an offscreen sprite
  and blitted.
- Flow particles are redrawn every frame indefinitely, so they now have a budget
  and thin to the strongest edges on large graphs instead of every edge carrying
  its own.
- The graph was re-ingested on every React render, reheating the force layout
  whenever anything unrelated changed.
- In 3D, bloom is computed at half resolution and sphere detail drops on large
  graphs.

Nothing was removed: glow and flow still render, and the Glow and motion toggle
in Solo Controls still turns them off.

## Verifying a download

Every package ships a `.sha256` beside it. The installers are not code-signed,
so Windows shows its unknown-publisher prompt; compare the checksum if you want
to confirm what you downloaded.
