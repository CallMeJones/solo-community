# Solo 0.12.9

Read a memory without the letterbox.

## Added

- **The memory details panel can be dragged wider.** Open a memory from the
  list, the 2D graph or the 3D graph, and the divider between it and the rest
  of the workspace is now a handle: drag it left to give a long memory the
  room to be read, double-click it to put the panel back to its normal width.
  The width is remembered for next time.

  It can also be moved with the arrow keys when the divider has focus, and it
  stops at a readable minimum and at three quarters of the workspace, so the
  panel cannot be dragged into a sliver or widened until the graph has nothing
  left to draw in. On a narrow window, where the panel already slides over the
  workspace rather than sitting beside it, there is nothing to divide and the
  handle stays out of the way.

## Install

Windows: press **Check for updates** in Solo, or run
`SoloSetup-0.12.9-x86_64.exe`. It installs per-user, without an administrator
prompt. This release ships for Windows only; Ubuntu stays on 0.12.3.

Every package ships a `.sha256` beside it. These installers are not
code-signed, so Windows shows its unknown-publisher prompt.
