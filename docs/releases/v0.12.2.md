# Solo 0.12.2

Small release adding a way to turn the memory graph's node names off.

## Memories

- **Labels** switch in the Memories toolbar, beside the 2D/3D toggle. The 2D
  graph paints a name beside every document and cluster, and beside memory
  nodes once you zoom in; on a library of any size that covers the graph in
  overlapping text. Turning it off leaves the nodes, the links and the flow.

  The choice is remembered across restarts. Off means off, including for the
  node you have selected — the reason to turn labels off is to see the shape
  of the graph rather than read it, and hovering a node still names it, as
  does the inspector on the right.

  Only shown in 2D. The 3D view has never drawn names into the scene.

## Verifying a download

Every package ships a `.sha256` beside it. The installers are not code-signed,
so Windows shows its unknown-publisher prompt; compare the checksum if you want
to confirm what you downloaded.

## Install

Windows: run `SoloSetup-0.12.2-x86_64.exe`. It installs per-user, without an
administrator prompt.

Ubuntu 24.04 x86-64: `sudo apt install ./solo-0.12.2-ubuntu24.04-amd64.deb`
