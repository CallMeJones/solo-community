# Solo 0.12.0 test 11

Public cross-platform Community pre-release candidate for Windows x86-64 and
Ubuntu 24.04 x86-64 testing.

This supersedes the Ubuntu-only `v0.12.0-linux-test.10` candidate with a
complete supported-OS release set.

- includes the Windows installer, Windows portable ZIP, Ubuntu 24.04 `.deb`,
  and checksums in one GitHub prerelease;
- keeps the Community Core and Web changes from Linux test 10: capability
  readiness, knowledge-extraction setup, section states, immediate backfill,
  daemon-aware doctor checks, isolated round-trip diagnostics, and the bundled
  retrieval evaluation corpus;
- retains full Community BYO knowledge extraction through local Ollama, direct
  Ollama Cloud, Ollama Cloud through a signed-in local daemon, custom Ollama
  endpoints, Anthropic, and OpenAI with explicit consent;
- verifies the embedded Web artifact before packaging each OS variant;
- installs and smokes the generated Ubuntu package on Ubuntu 24.04;
- builds, packages, installs, and smokes the generated Windows installer and
  portable ZIP on Windows.

Hosted providers process the memory content submitted for knowledge extraction
off-device. They remain disabled until the user explicitly selects and consents
to one. Local Ollama keeps that processing on the machine; direct Ollama Cloud
and cloud models reached through a signed-in local Ollama daemon process the
submitted content through Ollama's service.

This is not the stable 0.12.0 release.
