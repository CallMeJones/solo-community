# Solo 0.12.4

Choose which edition Solo updates to, straight from Solo Controls.

## Updates

- **Edition** sits beside *Check for updates*. It follows the Solo you have
  installed until you change it. Choosing **Pro** makes the next check offer
  the newest Solo Pro build, from its own public release repository; choosing
  **Community** offers Solo Community again. Either one installs over the Solo
  you have, in place, and keeps your Memory Library.
- Picking an edition only chooses which package is downloaded. Nothing is
  unlocked by the choice: a Pro build verifies its own licence, and without
  one it runs exactly as Community.
- Each edition installs only its own packages. The download is still checked
  against the `.sha256` published beside it, and discarded if it does not
  match.

## Solo account

- When the Solo you are running offers a Solo account (Solo Pro does), Solo
  Controls shows who this machine is signed in as and a **Sign in to your Solo
  account** button. Signing in happens in your browser; Solo restarts by itself
  once you approve. Community has no account, so for it nothing changes.

## Projects

- A host built on Community can add its own tab beside a project's overview.

## Verifying a download

Every package ships a `.sha256` beside it. These installers are **not**
code-signed, so Windows shows its unknown-publisher prompt; compare the
checksum if you want to confirm what you downloaded. Nothing in this release
should be described as signed.

## Install

Windows: run `SoloSetup-0.12.4-x86_64.exe`, or press *Check for updates* in
Solo Controls on 0.12.3. It installs per-user, without an administrator
prompt.

This release ships for Windows only. Ubuntu stays on 0.12.3.
