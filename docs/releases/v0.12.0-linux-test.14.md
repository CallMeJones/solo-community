# Solo 0.12.0 Test 14

Public pre-release candidate for hands-on Windows and Ubuntu 24.04 x86-64
testing of the in-app updater and the reworked Solo Controls window.

- adds Check for updates to Solo Controls: one press checks the Community
  releases, a second downloads, verifies the published SHA-256, and installs;
- keeps the update flow operator-triggered — nothing polls on a timer and
  nothing is reported home, so the offline-first install stays offline until
  the button is pressed;
- skips releases whose title marks them superseded, which previously meant the
  newest `.deb`-carrying release on Linux was one the maintainer had retracted;
- adds a Back / Solo Controls bar to every section of the Controls window;
  Settings and Connected Tools were previously reachable but not leaveable;
- restores page-level scrolling across the Controls window, and lets the
  connected-clients table scroll sideways instead of clipping its actions;
- adds a System / Dark / Light theme picker to Controls settings, which was
  previously only reachable from the tray menu;
- adds a per-row Find install probe that looks for Claude Desktop, Cursor and
  the Codex CLI themselves, separately from their Solo config;
- surfaces Settings and Logs directly on the Controls main row.

Updating from a build earlier than test 14 exercises the new updater end to
end. On Linux the download is verified and then installed manually, because a
`.deb` needs root and cannot install unattended.

This is not the stable 0.12.0 release.
