# Solo 0.12.0 Linux test 6

Public pre-release candidate for hands-on Ubuntu 24.04 x86-64 testing.

- supersedes Linux test 5 with the verified upstream `glib` iterator soundness
  fix backported into the GTK 3 dependency line;
- verifies the patched `glib` source hash and exact Cargo resolution before
  audit, test, build, and packaging jobs run;
- adds an optimized forward/backward iterator regression test for the patched
  code path;
- uses the Node.js 24 artifact uploader pinned to an immutable commit;
- embeds the audited clean-root Community Web commit recorded in provenance;
- installs the generated `.deb` in CI and runs memory, document, backup,
  restore, MCP, single-database, and tray GUI smokes against the installed app;
- publishes the package, checksum, manifest, SBOM, and build attestation only
  after every release gate succeeds.

This is not the stable 0.12.0 release.
