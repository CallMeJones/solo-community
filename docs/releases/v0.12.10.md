# Solo 0.12.10

GitHub Copilot, set up for you.

## Added

- **`solo setup-client copilot`.** Copilot reads VS Code's `mcp.json`, which is
  shaped differently from the configs Solo already wrote: the map is `servers`
  rather than `mcpServers`, and VS Code reaches an HTTP server itself. So Solo's
  address goes in directly — nothing to install, no `npx mcp-remote` bridge in
  the way.

  ```
  solo setup-client copilot --transport http --dry-run
  ```

  Run it with `--apply` to write the file, which is backed up first if it
  exists. Other MCP servers already in that file are left alone, and no
  passphrase is ever written into a client config.

- **Connected apps lists Copilot** beside Codex, Claude Desktop and Cursor,
  with the same Copy dry-run, Copy install and Copy Doctor buttons.

## Fixed

- **`setup-client verify` judged configs by the wrong shape.** It looked for an
  `mcpServers` map and insisted every entry name a command to run, so a client
  whose config reaches Solo over HTTP would have been reported as invalid even
  when it was correct. Verifying, merging and previewing now each read the key
  and the entry shape the client actually uses.

## Install

Windows: press **Check for updates** in Solo, or run
`SoloSetup-0.12.10-x86_64.exe`. It installs per-user, without an administrator
prompt. This release ships for Windows only; Ubuntu stays on 0.12.3.

Every package ships a `.sha256` beside it. These installers are not
code-signed, so Windows shows its unknown-publisher prompt.
