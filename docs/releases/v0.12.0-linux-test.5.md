# Solo 0.12.0 Linux test 5

Public pre-release candidate for hands-on Ubuntu 24.04 x86-64 testing.

- embeds the audited clean-root Community Web commit recorded in provenance;
- pins every GitHub Actions dependency to an immutable commit;
- runs release builds and tests against the committed Cargo lockfile;
- shares one fail-closed, signed-MSVC-runtime packaging gate with the paid build;
- includes a Community Web dependency graph with zero known npm advisories;
- removes all known Rust dependency vulnerabilities and gates CI and publishing
  with an exact, lockfile-pinned `cargo-audit` version;
- retries transient embedding-model download failures with bounded backoff;
- declares the `libxkbcommon-x11-0` tray runtime dependency;
- installs the generated `.deb` in CI;
- runs memory, document, backup, restore, MCP, and one-database smokes against
  the installed CLI;
- launches the installed tray under Xvfb and DBus before publishing the
  pre-release artifact.

This is not the stable 0.12.0 release.
