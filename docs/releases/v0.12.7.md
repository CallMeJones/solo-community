# Solo 0.12.7

Which build you are running, and why Solo will not start.

## Added

- The **version** of the running Solo now sits under *Local Community library*
  in the sidebar, so you can tell at a glance which build you are on without
  opening Health.

## Fixed

- The unlock screen reported `daemon child exited unexpectedly:
  ExitStatus(1)` whatever the cause. Solo had already written the reason to
  its log, but a window that will not open is a window you cannot read a log
  in. It now shows that line: *Solo could not start.* followed by what the
  daemon actually said — a passphrase that does not open the library, an
  embedder that does not match it, a port already taken.

## Install

Windows: press **Check for updates** in Solo, or run
`SoloSetup-0.12.7-x86_64.exe`. It installs per-user, without an administrator
prompt. This release ships for Windows only; Ubuntu stays on 0.12.3.

Every package ships a `.sha256` beside it. These installers are not
code-signed, so Windows shows its unknown-publisher prompt.
