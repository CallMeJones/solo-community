# Solo 0.12.0 Linux test 10

Public pre-release candidate for hands-on Ubuntu 24.04 x86-64 testing.

- supersedes Linux test 9 by consolidating Solo Community Core and Web into
  one public repository and release unit;
- builds the Web app from `apps/web` and verifies its embedded Rust assets,
  provenance, source tree, and release commit before packaging;
- removes the development-time dependency on a sibling Solo Web checkout;
- runs the complete Community Web type, lint, unit, browser, boundary,
  dependency, and SBOM gates alongside the Rust gates;
- installs the generated `.deb` in CI and runs memory, document, backup,
  restore, MCP, single-database, and tray GUI smokes against the installed app;
- publishes the package and checksum only after every release gate succeeds.

This is not the stable 0.12.0 release.
