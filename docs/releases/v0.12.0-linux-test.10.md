# Solo 0.12.0 Linux test 10

Public pre-release candidate for hands-on Ubuntu 24.04 x86-64 testing.

- makes recall, documents, clustering, knowledge extraction, facts, entities,
  graph relationships, and contradiction readiness visible in Solo Web;
- supports local Ollama, direct Ollama Cloud, Ollama Cloud through a signed-in
  local daemon, custom Ollama endpoints, Anthropic, and OpenAI with explicit
  processing-location consent;
- adds immediate derived-memory backfill with progress, shared work
  coordination, failure states, and live capability explanations;
- adds live-daemon diagnostics and an isolated `solo doctor --round-trip`
  check that does not add test memories to the real library;
- retains full Community knowledge extraction and graph functionality;
- ships the bundled all-MiniLM-L6-v2 retrieval model and a repeatable retrieval
  evaluation corpus; MiniLM remains local and does not require Ollama;
- consolidates Community Core and Web into one release unit and verifies the
  embedded Web asset provenance before packaging;
- installs the generated `.deb` and exercises memory, documents, backup,
  restore, MCP, single-database, Ollama, and tray workflows on Ubuntu 24.04.

Hosted providers process the memory content submitted for knowledge extraction
off-device. They remain disabled until the user explicitly selects and consents
to one. Local Ollama keeps that processing on the machine; direct Ollama Cloud
and cloud models reached through a signed-in local Ollama daemon process the
submitted content through Ollama's service.

This is not the stable 0.12.0 release.
