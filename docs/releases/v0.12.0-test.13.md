# Solo 0.12.0 Test 13

Public pre-release candidate for hands-on Windows and Ubuntu 24.04 x86-64
upgrade validation.

- supersedes test 12 with neutral release naming across Windows and Ubuntu
  assets;
- adds a Windows setup installer asset, `SoloSetup-0.12.0-test.13-x86_64.exe`,
  alongside the portable Windows ZIP;
- keeps Ubuntu packaging as a `.deb` asset with Ubuntu-specific naming;
- updates the transitive `webbrowser` dependency from 1.2.1 to 1.2.2,
  resolving RUSTSEC-2026-0257;
- preserves the real 0.11.x `.solo` profile migration compatibility from test
  11, including previous `tenants/default.db` promotion and legacy registry
  quarantine behavior.

This is not the stable 0.12.0 release.
