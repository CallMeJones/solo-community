# Solo 0.12.0 Linux test 11

Public pre-release candidate for hands-on Ubuntu 24.04 x86-64 testing and
Windows upgrade validation.

- supersedes Linux test 10 by supporting real 0.11.x `.solo` profiles that use
  the previous `tenants/default.db` layout;
- validates the previous encrypted default library before promoting it to the
  Community `solo.db`, so a wrong key leaves the old layout untouched;
- preserves readable previous admin audit history and quarantines unreadable
  obsolete `tenants_index.db` files under `migration-retired/`;
- adds `solo doctor` diagnostics for previous-layout profiles before startup;
- logs the resolved `solo.exe` path when Solo Controls cannot spawn the daemon;
- installs the generated `.deb` in CI and runs memory, document, backup,
  restore, MCP, single-database, and tray GUI smokes against the installed app.

This is not the stable 0.12.0 release.
