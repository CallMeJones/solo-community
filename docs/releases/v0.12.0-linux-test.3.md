# Solo 0.12.0 Linux test 3

Private/public pre-release candidate for hands-on Ubuntu 24.04 x86-64 testing.

- embeds the clean-root Community Web commit recorded in provenance;
- declares the `libxkbcommon-x11-0` tray runtime dependency;
- installs the generated `.deb` in CI;
- runs memory, document, backup, restore, MCP, and one-database smokes against
  the installed CLI;
- launches the installed tray under Xvfb and DBus before publishing the
  pre-release artifact.

This is not the stable 0.12.0 release.
