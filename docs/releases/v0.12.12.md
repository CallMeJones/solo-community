# Solo 0.12.12 — cross-platform preview

This preview makes the same Community source available as native Windows,
Ubuntu 24.04, Apple Silicon Mac and Intel Mac downloads. It includes the local
MCP server, automatic recall hooks, offline embedding model and desktop controls.

## Downloads

- **Windows x64:** `SoloSetup-0.12.12-x86_64.exe`, or the portable
  `solo-cli-0.12.12-x86_64-pc-windows-msvc.zip`.
- **Ubuntu 24.04 x64:** `solo-0.12.12-ubuntu24.04-amd64.deb`, or
  `solo-cli-0.12.12-x86_64-unknown-linux-gnu.tar.gz`.
- **Apple Silicon, macOS 15 or newer:**
  `solo-0.12.12-aarch64-apple-darwin.dmg` or its `.tar.gz` equivalent.
- **Intel, macOS 15 or newer:**
  `solo-0.12.12-x86_64-apple-darwin.dmg` or its `.tar.gz` equivalent.
- **Codex and Claude Code plugins:** `solo-agent-plugin-0.1.0.zip` installs
  the MCP connection, recall hooks and skills together. It exposes all 39 MCP
  tools, including writes, documents, attachments and review operations.
  See the [plugin installation guide](../agent-plugins.md).

Each download has a SHA-256 sidecar. Platform manifests identify the source
commit and GitHub build run. Native package jobs also attest build provenance.

## Install

Windows: run Setup, then restart your coding assistant so it sees Solo on PATH.
The preview installer is unsigned and can show an unknown-publisher prompt.

Ubuntu: run `sudo apt install ./solo-0.12.12-ubuntu24.04-amd64.deb`, then launch
Solo from the application menu. Other Linux distributions are source-build
targets; the binary desktop package is certified on Ubuntu 24.04.

Mac: open the DMG and drag `Solo.app` into Applications. Open Solo and create
or unlock your library. The app has an ad-hoc integrity signature; it is not
Apple Developer ID signed or notarized. macOS may require approval in
Privacy & Security. Verify the download's source and checksum before approving.
For terminal commands and recall hooks, run `bash install-cli.sh` from the
mounted image or extracted archive, add `$HOME/.local/bin` to your shell PATH,
and restart your assistant. The helper preserves existing regular files.

All packages carry the pinned local embedding model. Existing libraries keep
their configured embedder; this release does not migrate their vectors.

## Known limitation

Automatic contradiction detection is not currently connected to the background
extraction pipeline. Conflicting facts can therefore exist without appearing
in the contradiction queue. Listing and resolving existing contradiction
records work, but a newly extracted conflict may not enter that workflow.
This preview does not claim that gap is fixed.

Windows and Ubuntu packaging have installed-workflow checks. Mac builds run
native packaged-CLI memory, document, MCP and backup/restore checks, plus app
signature and mounted-image checks. Physical Mac desktop acceptance remains
manual. This GitHub prerelease does not replace the current stable release.
